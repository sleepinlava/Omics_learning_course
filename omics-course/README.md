# 从数据到证据：组学分析中文实践课

面向有基础生物学知识、尚未独立完成分析的学习者。课程覆盖 bulk RNA-seq、scRNA-seq、空间转录组、LC–MS 代谢组，以及 GEO、KEGG 与 meta 分析。**先学如何提出可检验的问题，再学运行软件，最后学判断结论是否成立。** bulk 和单细胞仍然是研究与学习的基础，不因出现时间较早而失去价值。

本课程是现有开放教程的中文学习路线、原理补充和运行入口，不替代原作者教程。代码调用 DESeq2、Seurat、Squidpy、xcms、limma 等成熟工具，不重新实现分析算法。参考资源核对日期：2026-10-17；课程没有按 GitHub 星数给工具排名。

## 1. 从这里开始

在仓库根目录运行：

```bash
# 只读检查：已安装依赖、现有数据与文件摘要
python omics-course/scripts/00_check.py
# 无需下载、仅用基础 R：统计直觉与模拟实验
Rscript omics-course/scripts/01_statistics_lab.R
# 使用仓库已有 airway 整数计数，不依赖 airway 数据包
Rscript omics-course/scripts/02_bulk_airway.R
# 使用 Seurat 自带小型对象：只练习对象和降维，不代表完整实验
Rscript omics-course/scripts/03_single_cell.R --demo
```

输出保存在 `omics-course/results/`；可先打开 [已生成结果导读](results/README.md)。实际验证记录见 [验证状态](VALIDATION.md)，不能把“有下载命令”理解为“数据已下载”，也不能把“脚本语法通过”理解为“分析成功”。联网环境下的完整数据课程见 [环境与数据准备](00_setup/README.md)。

## 2. 建议学习路线（主线 8–10 周，扩展 3–4 周；每周约 6–10 小时）

## 3. 每章怎样学

1. 先写一句生物学问题，指出真正独立的样本是什么。
2. 按本章指定小节阅读上游教程，而不是一次读完整个网站。
3. 跑最小案例，保存输入来源、参数、软件版本和完整结果表。
4. 解释每一步改变了什么；故意改一个参数，观察结果如何变化。
5. 完成本章练习，并对照 [习题与参考答案](exercises/README.md)。

## 4. 文件夹说明

- `00_setup/`–`09_meta_analysis/`：中文教学正文；每章都有目标、输入、步骤、原理、局限和作业。
- `scripts/`：薄层教学脚本，调用成熟分析包；既有可离线运行案例，也有下载后运行案例。
- `env/`：按模块安装依赖，避免一次安装所有工具。
- `resources/`：上游教程、数据来源、引用与获取脚本配置。
- `templates/`：样本表、分析计划、结果报告模板。
- `data/`：新下载数据与小型导出数据；bulk 输入直接读取仓库原有 `data/counts/`。
- `results/`：本课程生成的图、表、对象和会话信息。

## 5. 最重要的学习边界

PBMC3k 适合学细胞类型，单张 Visium 切片适合学空间模式；两者都不能凭大量细胞/spot 代替多个独立供者。faahKO 是截取过的历史练习数据，缺少现代完整 QC 设计，不能据此宣称鉴定了全代谢组。模拟数据均明确标为模拟。

NGS Analysis Workbench 用于本课程的“科学问题—输入—设计—证据—限制”框架；本次没有注册或提交云端分析任务。代谢组质谱分析采用其领域专用工具，不将其当作 NGS 计数流程。
